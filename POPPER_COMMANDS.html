Popper — PowerShell Command Reference

Autonomous alpha research & falsification  ·  v0.3
CLI = python -m popper.cli <cmd>

▶ Start every session here (2 lines)

cd C:\Users\Jakes\Projects\popper          # the project ROOT — not .venv\scripts
.\.venv\Scripts\Activate.ps1                # prompt now shows (.venv); `python` = the venv's
After activating, every command below can be typed as popper <cmd> or python -m popper.cli <cmd>. Didn't activate? Prefix any command with & .\.venv\Scripts\python.exe -m popper.cli
⚠ Common mistake. Do NOT cd into .venv\Scripts, and do NOT run a bare python.exe — PowerShell runs the global Python (no popper installed) → ModuleNotFoundError: No module named 'popper'. Always run from the project root and use the venv's Python (activate, or call it by full path with &).

1Seed & inspect memory

# load the example hypotheses into alpha memory
popper seed
# print current counts (JSON)
popper stats

2Run ONE hypothesis

Full loop: store → backtest → falsify → judge → store verdict.

popper run --hypothesis examples\hypotheses\ny_open_momentum.yaml

# fixed period:
popper run --hypothesis examples\hypotheses\jake_london_regime_pullback.yaml `
    --start 2024-01-01 --end 2025-12-31

# strictness + run even if near-duplicate:
popper run --hypothesis examples\hypotheses\rsi_knife_edge.yaml `
    --signal-edge-mode strict --allow-stale

--hypothesis (required) · --start/--end YYYY-MM-DD · --signal-edge-mode loose|balanced|strict · --allow-stale

3Autonomous research loop

The Director proposes alphas; the gauntlet falsifies each — hands-off.

popper research --iterations 3
popper research --iterations 50 --no-exit-menu `
    --signal-edge-mode balanced

--iterations N (default 10) · --no-exit-menu · --signal-edge-mode

4API backend

Serve the API the dashboard talks to.

popper serve   # → http://127.0.0.1:8000/docs

5No-activation form

Every command works without activating — call the venv Python by path (& = run this exe):

& .\.venv\Scripts\python.exe -m popper.cli stats
& .\.venv\Scripts\python.exe -m popper.cli research --iterations 3

6Full stack (GUI)

Boots API :8000 + dashboard :5173 + browser. First run auto-installs + seeds.

.\Popper.cmd            # or double-click it

Dashboard → http://localhost:5173

7Stop / free ports

Close the two minimized windows, or free the ports:

Get-NetTCPConnection -LocalPort 8000,5173 -State Listen -EA SilentlyContinue `
  | Select -Expand OwningProcess -Unique `
  | ForEach-Object { Stop-Process -Id $_ -Force }

8Tests

# full suite
python -m pytest -q
# DSL + SMC + regime (no look-ahead)
python -m pytest tests\test_dsl.py tests\test_smc.py -q
PowerShell notes. .\ runs a script/exe in the current folder · ` (backtick) at line-end continues a command · & runs an exe by path · scripts blocked? Set-ExecutionPolicy -Scope Process Bypass. Hypotheses live in examples\hypotheses\.
Commands: run · research · seed · stats · serve.   Always from C:\Users\Jakes\Projects\popper with the venv active (or via & .\.venv\Scripts\python.exe -m popper.cli).
